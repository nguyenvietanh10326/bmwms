# Coding Workflow

For every task, follow this workflow:

1. Analyze the user's request and inspect the relevant code.
2. Do not modify any files during the analysis phase.
3. Provide a clear implementation plan.
4. List the files that will be modified.
5. Wait for explicit user approval before making any code changes.
6. After approval, implement only the approved plan.
7. Do not modify unrelated files.
8. Do not delete existing functionality unless explicitly requested.
9. Keep changes minimal and focused.
10. After implementation, summarize all changes made.
11. Always communicate with the user in Vietnamese.
12. Keep code, identifiers, and existing code conventions unchanged.
